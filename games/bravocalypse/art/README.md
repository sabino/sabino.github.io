# BRAVOCALYPSE artwork

`title-scene.png` and `logo.png` were generated for this project with OpenAI image generation on 2026-09-11, at the user's request. They are original game presentation assets, not screenshots of the playable renderer.

The title artwork establishes the red velvet, ivory, brass and theatrical comedy direction. The logo reads BRAVOCALYPSE! and is used in the songbook, initial loader, cast loading overlay and concert hall.

Exact generation prompts are recorded in `docs/art-prompts.json`.
