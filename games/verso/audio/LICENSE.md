See [PROVENANCE.json](PROVENANCE.json) for every exact input file, input SHA-256, creator/source URL, edited interval, transform and final output SHA-256. Foley edits: mono24kHz PCM16, silence trimming with preserved onset/tail, short edge fades, conservative peak normalization and atlas spacing. Ambience edits: bounded excerpts, equal-power seam overlap, RMS/peak adjustment and80kbps MP3. Only the first4MiB of each large Thimras field recording was requested (HTTP206 range); the remainder was neither downloaded nor redistributed.
