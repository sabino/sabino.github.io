04 / the engineer behind the studio

i still design,
code, and ship.

I founded Sabino Software because I do my best work close to the system: understanding what is wrong, choosing an architecture, writing the code, and helping the team own it afterward.

Over 19+ years in professional software engineering and roughly a decade in production data platforms, I have worked inside startups, scale-ups, consultancies, and large enterprises, including Nubank, Conta Azul, Transfeera, Accenture, NTT DATA, and TOTVS.

My range now includes distributed data, backend services, cloud platforms, developer experience, applied AI, and hardware-integrated software. I still prefer the same working pattern: make the problem concrete, build the critical path, explain the decisions, and leave the system easier to operate.

  • principle_01

    make decisions executable

    The important choices become clearer when the design can actually run.

  • principle_02

    make the system understandable

    Documentation, observability, and a usable local workflow are production features.

  • principle_03

    leave ownership with the team

    Good delivery creates capability instead of dependence on the consultant.

  • principle_04

    understand before replacing

    Modernization starts by learning why the current system became difficult.
